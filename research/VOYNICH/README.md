# Biblioteca de experiências Voynich (M12–M17)

Reuni os artefactos locais disponíveis para reutilização e auditoria. O pacote contém 141 ficheiros, com dados públicos, resultados, relatórios, protocolos, código e testes.

## Experiências encontradas

- **M12:** políticas concorrentes em mundos sintéticos; confirmação concluída, sem promoção geral.
- **M13:** cobertura de contextos versus desacordo; confirmação concluída com 2 gates aprovados e 2 reprovados, sem promoção geral.
- **M14-R:** reparações concorrentes em mundos sintéticos; 4/6 critérios passaram, sem promoção geral.
- **M15:** piloto de SFT para seleção de consultas em dados sintéticos M14.
- **M16:** currículo interativo L4/L5 sintético; os gates do protocolo foram aprovados em três sementes.
- **M17:** benchmark textual sintético; a avaliação do modelo base foi interrompida e não produziu métricas válidas.

**Estes ensaios não usaram fólios históricos do manuscrito Voynich ou Egerton e não demonstram descodificação do manuscrito.**

O ZIP inclui dados de desenvolvimento/validação, logs públicos e resultados históricos; não contém verdades privadas, pesos de modelos nem resultados individuais de diagnóstico M17. Resultados confirmatórios/de transferência são arquivísticos e não devem ser reutilizados como dados inéditos. O repositório permanece privado. O manifesto de hashes está dentro do ZIP.
