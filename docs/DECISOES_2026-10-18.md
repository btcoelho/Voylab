# Decisões de 18/10/2026 (08:09)

**Arquitetura: autonomia condicionada, com o enquadramento separado da investigação.** Proposta do Bruno, com os acrescentos do Claude aceites a 18/10, 08:09.

- **C1–C2 (reconhecimento e enquadramento) são um módulo próprio**, medido à parte de C3–C5. A saída obrigatória é uma especificação formal verificável, não uma explicação em linguagem natural. Um modelo pode ser fraco numa parte e forte na outra; os resultados não se misturam.
- **Critério de resolubilidade.**
  - Uma ambiguidade é *resolúvel* se todas as interpretações razoáveis levam à mesma decisão, ou se os dados distinguem entre elas.
  - *Exige esclarecimento* se as interpretações levam a decisões diferentes e nada no problema as separa.
- **Três saídas para uma ambiguidade:**
  1. resolver com um pressuposto declarado;
  2. perguntar, quando existe quem saiba;
  3. ramificar, quando ninguém sabe: conclusões condicionais por pressuposto e a evidência que os distinga como objetivo de investigação. É o caso típico do Voynich.
- **Bloqueio parcial.** Bloqueiam-se só as conclusões que dependem da decisão pendente; a investigação independente continua.
- **Registo de pressupostos.** Cada pressuposto tem id, origem (dado, inferido, confirmado) e as conclusões que dependem dele; cada conclusão herda essas marcas. Um pressuposto nunca pode ser apresentado como dado do problema.
- **Ordem:** fechar a fase 3 e a fase 5 do instrumento (o que se conclui sobre os acertos dos modelos), e só depois desenhar a avaliação de C1–C2. O primeiro caso natural é o prompt v3, cujos defeitos já são conhecidos; os restantes vêm de especificações bem postas estragadas de forma controlada.
